# 汉字小达人题库

上海市小学生“汉字小达人”活动的历年真题和模拟题，整理成结构化题库，并做成一个手机上也能用的刷题页面。

在线刷题：<https://lovvvve.github.io/hanzi-xiaodaren/>

## 收录内容

| 组 | 套卷 | 题数 |
|---|---|---|
| 真题 | 第七届市赛（2020）、第八届市赛（2021）、2025 区赛 | 150 + 150 + 105 = 405 |
| 模拟 | 《聪明小豆丁》2022、2023、2026 年 7&8 月刊，2025 官方模拟题 | 345 + 345 + 350 + 350 = 1390 |

题型：看拼音写词、选字补词、成语填空、挑字成语、字词辨析、诗句填空、字格连诗句、情境名句、文化常识、判断、字义、文言成语、古文字识字。

## 页面功能

- 选择题、判断题点选项即判分。
- 挑字成语、字格连诗句：按顺序点字，填满自动判分。
- 其他填空题：在田字格里用手指或触控笔手写，看答案后逐字对照，自己判对错。
- 错题本：答错的题自动收录，同一题连续答对两次标为“已掌握”；也可以手动收入、移出。错题本保存在当前设备的浏览器里，换设备或清除浏览器数据后看不到。
- “看答案”模式：直接显示全部答案和解析。

## 答案

答案一律以原始答案文件为准，每道题都已与答案文件逐题核对。卷面个别印错、而答案文件写明了正确内容的选项和字格，已按答案文件修正，并在题目的“整理备注”里注明原卷印的内容。

第七届市赛第 106–120 题（古文字）的答案，答案文件自己注明“基本是蒙的”。

## 目录

```
data/                原始资料：题目 PDF、答案文件（txt / xlsx / pdf / png）
题库/
  真题/  模拟/        每套卷一个 JSON，字段说明见 题库/README.md
  assets/            古文字字形、非规范字等裁图
  index.json         总索引；all.jsonl 每行一题
  validate.py        校验题库 JSON
  build.py           生成 index.json、all.jsonl、待核对.md
  web/               页面模板与生成脚本
index.html           刷题页（由 题库/web/render.py 生成）
```

《中文自修·聪明小豆丁》2023 年 7&8 合刊的整本 PDF 有 324M，超过 GitHub 单文件上限，没有上传；其中的模拟题已单独收在 `data/市赛真题/2023年7&8月/汉字小达人模拟题2023.pdf`。

## 重新生成

```bash
python3 题库/validate.py 题库/真题/*.json 题库/模拟/*.json
python3 题库/build.py
python3 题库/web/render.py 合并     # 生成根目录 index.html
```
